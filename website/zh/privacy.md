# 隐私政策

本政策说明 OpenKara 网站和桌面应用使用了哪些数据、数据在哪里处理，以及用户如何删除数据。

**最后更新：** 2026 年 4 月 21 日

## 适用范围

本隐私政策适用于 OpenKara 网站和 OpenKara 桌面应用。OpenKara 是一款开源卡拉 OK 应用，帮助用户将已有的音乐准备为卡拉 OK 曲目并进行播放。

OpenKara 项目不为核心桌面工作流运营托管后端服务。大多数处理直接在用户设备上完成。

## 项目运营方

OpenKara 以开源软件项目和网站的形式维护。除非在特定分发渠道中明确声明了独立的商业实体或服务协议，本政策中提及的"OpenKara"、"我们"或"项目"均指 OpenKara 项目的维护者及公共网站 [openkara.103279.xyz](https://openkara.103279.xyz/)。

## 网站数据

OpenKara 公共网站用于介绍项目、提供下载链接以及指向源代码和文档的链接。

项目本身不会通过网站有意收集超出标准 Web 服务器日志或网站主机所提供分析工具正常范围的个人数据。如果网站由 GitHub Pages 等第三方托管，该主机可能会根据其自身政策处理 IP 地址、浏览器信息或访问日志等技术信息。

## 我们不主动收集的数据

OpenKara 不会通过项目运营的后端有意收集广告标识符、行为画像、通讯录、精确位置、支付卡信息或用户音乐库内容，用于正常桌面工作流。

如果用户选择通过 OpenKara 与第三方服务交互，传输给该提供商的任何信息受提供商自身政策和用户授予权限的约束。

## 桌面应用数据

OpenKara 将卡拉 OK 曲库数据本地存储在用户设备上。这可能包括歌曲元数据、歌词、缓存的音轨、封面、本地配置和远程曲库工作副本。

OpenKara 仅在用户请求应用功能时访问本地文件，例如导入歌曲、读取元数据、渲染歌词、创建卡拉 OK 音轨或同步用户选择的远程曲库。

## 云提供商数据

当用户连接 Google Drive、Dropbox、WebDAV 或 OpenKara 支持的其他远程存储提供商时，应用仅访问浏览、创建、读取、更新、同步或删除该 OpenKara 远程曲库文件所需的数据。

对于基于 OAuth 的提供商，OpenKara 可能会接收帐户标识信息（如电子邮件地址或稳定帐户标识符），以便在应用内区分已连接的帐户。

OpenKara 不会将提供商数据用于广告、画像、转售或无关分析。

如果 OpenKara 从 Google API 接收信息，OpenKara 对该信息的使用和向任何其他应用的传输将遵守 Google API 服务用户数据政策，包括其有限使用要求。

## 凭据存储

OpenKara 使用操作系统凭据存储（如 macOS 钥匙串、Windows 凭据管理器或 Linux 系统密钥环）在用户设备上存储敏感的远程曲库凭据。

非敏感的曲库注册元数据可能存储在应用的本地配置文件中，以便用户稍后可以重新连接到同一本地或远程曲库。

桌面发布包中捆绑的官方 OAuth 客户端元数据可能标识 OpenKara 应用本身，但它与每个用户自己的令牌是分开的。用户特定的刷新令牌和访问令牌旨在保存在该用户设备上由操作系统管理的安全存储中。

## 歌词和网络请求

OpenKara 可能会发起网络请求以获取时间同步歌词或访问用户明确连接的远程存储提供商。这些请求仅用于提供用户请求的应用功能。

音乐分离、本地播放和本地库管理不需要将用户的歌曲发送到 OpenKara 运营的服务器。

## 安全性

OpenKara 的设计使核心处理在用户自己的设备上进行，敏感的远程曲库凭据在可用时使用平台安全功能存储。然而，没有任何软件或存储机制可以保证绝对安全。

用户仍有责任保护其设备、操作系统帐户、备份以及连接到 OpenKara 的任何第三方云帐户。

## 数据共享

OpenKara 项目不出售或代理用户数据。用户文件、歌词缓存和远程曲库凭据不会发送到 OpenKara 运营的后端，因为项目没有为核心桌面应用运行后端。

数据可能会在用户设备和用户选择使用的第三方服务（如 Google Drive、Dropbox 或 WebDAV 服务器）之间直接传输。

## 保留与删除

用户可以通过删除本地曲库数据、移除应用配置或在 OpenKara 内断开远程曲库来控制数据保留。

用户也可以从相关提供商帐户设置中撤销 OAuth 访问，这会使应用的访问令牌失效。

因为项目没有为核心桌面工作流运行中央帐户系统，数据删除通常意味着移除本地应用数据、从用户选择的存储提供商中删除同步文件，以及在适用时撤销提供商访问权限。

## 儿童隐私

OpenKara 并非专门面向儿童。如果用户在其所在司法管辖区不具备法律上授权第三方服务或管理内容权利的资格，应在家长、监护人或其他授权成人的适当许可下使用 OpenKara。

## 政策变更

随着 OpenKara 网站、云集成或合规义务的变化，本隐私政策可能会更新。OpenKara 网站上发布的最新版本是网站和应用新使用的当前版本。

## 开源

OpenKara 以开源软件形式分发。源代码公开可用，用户可以在代码仓库中查看本地数据处理、凭据存储和远程曲库同步的工作方式。

如有项目问题、错误报告或隐私相关疑虑，请使用 GitHub 代码仓库的问题跟踪器或 OpenKara 项目主页和代码仓库中发布的联系渠道。
