# 隐私政策

本政策说明 OpenKara 网站和桌面应用用到了哪些数据、数据在哪里处理，以及你如何删除这些数据。

**最后更新：** 2026 年 4 月 21 日

## 适用范围

本隐私政策适用于 OpenKara 网站和 OpenKara 桌面应用。OpenKara 是一款开源卡拉 OK 应用，帮你把已有的音乐准备成卡拉 OK 曲目并播放。

OpenKara 项目没有为核心桌面工作流运营托管后端。大多数处理直接在你的设备上完成。

## 项目运营方

OpenKara 以开源软件项目和网站的形式维护。除非在某个分发渠道里明确声明了独立的商业实体或服务协议，否则本政策里提到的"OpenKara"、"我们"或"项目"都指 OpenKara 项目的维护者以及公共网站 [thedavidweng.github.io/OpenKara/](https://thedavidweng.github.io/OpenKara/)。

## 网站数据

OpenKara 公共网站用来介绍项目、提供下载链接，以及指向源代码和文档的链接。

项目本身不会通过网站刻意收集超出标准 Web 服务器日志或网站托管方提供的常规分析范围的个人数据。如果网站由 GitHub Pages 之类的第三方托管，托管方可能会根据它自己的政策处理 IP 地址、浏览器信息或访问日志等技术信息。

## 我们不会主动收集的数据

OpenKara 不会通过项目运营的后端主动收集广告标识符、行为画像、通讯录、精确位置、支付卡信息或用户音乐库内容，用于正常的桌面工作流。

如果你选择通过 OpenKara 与第三方服务交互，传给该服务的任何信息都受该服务自己的政策和你授予的权限约束。

## 桌面应用数据

OpenKara 把卡拉 OK 曲库数据存在你的设备本地，可能包括歌曲元数据、歌词、缓存的分轨、封面、本地配置和远程曲库的工作副本。

OpenKara 只在你请求应用功能时访问本地文件，比如导入歌曲、读取元数据、渲染歌词、生成卡拉 OK 分轨或同步你选择的远程曲库。

## 云存储服务数据

当你连接 Google Drive、Dropbox、WebDAV 或 OpenKara 支持的其他远程存储服务时，应用只会访问浏览、创建、读取、更新、同步或删除该 OpenKara 远程曲库文件所需的数据。

对于基于 OAuth 的服务，OpenKara 可能会收到账号标识信息（比如邮箱地址或稳定的账号 ID），用来在应用里区分已连接的账号。

OpenKara 不会把服务数据用于广告、画像、转售或无关的分析。

如果 OpenKara 从 Google API 接收到信息，OpenKara 对该信息的使用和向任何其他应用的传输将遵守 Google API 服务用户数据政策，包括其中的有限使用要求。

## 凭据存储

OpenKara 使用操作系统的凭据存储（比如 macOS 钥匙串、Windows 凭据管理器或 Linux 系统密钥环）把敏感的远程曲库凭据存在你的设备上。

非敏感的曲库注册元数据可能存在应用的本地配置文件里，方便你之后重新连接到同一个本地或远程曲库。

桌面发布包里捆绑的官方 OAuth 客户端元数据标识的是 OpenKara 应用本身，和你自己的令牌是分开的。用户专属的刷新令牌和访问令牌只留在你的设备上，由操作系统的安全存储管理。

## 歌词和网络请求

OpenKara 可能会发起网络请求来获取时间同步歌词，或者访问你明确连接的远程存储服务。这些请求只是为了提供你请求的应用功能。

音乐分离、本地播放和本地曲库管理不需要把你的歌曲发到 OpenKara 运营的服务器。

## 安全性

OpenKara 的设计是把核心处理放在你自己的设备上，敏感的远程曲库凭据在可用时用平台安全功能存储。但没有任何软件或存储机制能保证绝对安全。

你仍然有责任保护自己的设备、操作系统账号、备份以及连接到 OpenKara 的任何第三方云账号。

## 数据共享

OpenKara 项目不出售也不代理用户数据。用户文件、歌词缓存和远程曲库凭据不会发到 OpenKara 运营的后端，因为项目没有为核心桌面应用运行后端。

数据可能在你设备和第三方服务之间直接传输，比如 Google Drive、Dropbox 或 WebDAV 服务器。

## 保留和删除

你可以通过删除本地曲库数据、移除应用配置或在 OpenKara 里断开远程曲库来控制数据保留。

你也可以从相关服务的账号设置里撤销 OAuth 授权，这会让应用的访问令牌失效。

因为项目没有为核心桌面工作流运行中央账号系统，数据删除通常意味着删除本地应用数据、从你选择的存储服务里删除同步文件，以及在适用时撤销服务访问权限。

## 儿童隐私

OpenKara 不是专门面向儿童的。如果你所在的司法管辖区认为你还不具备授权第三方服务或管理内容权利的法律资格，请在家长、监护人或其他授权成人的许可下使用 OpenKara。

## 政策变更

随着 OpenKara 网站、云集成或合规义务的变化，本隐私政策可能会更新。OpenKara 网站上发布的最新版本是网站和应用新使用的当前版本。

## 开源

OpenKara 以开源软件形式分发。源代码公开可用，你可以在代码仓库里查看本地数据处理、凭据存储和远程曲库同步的工作方式。

## 联系方式

如有项目问题、错误报告或隐私相关的疑虑，请使用 GitHub 代码仓库的 Issue 跟踪器，或 OpenKara 项目主页和代码仓库里公布的联系渠道。
