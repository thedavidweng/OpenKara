# Changelog

## 0.9.0 - 2026-06-03

### Added

- **Streaming playback:** ring-buffer streaming decode for local and remote audio, chunked cache with LRU eviction and prefetch tracking, remote Range fetch with token refresh, bandwidth monitoring with automatic low-bitrate proxy mode for slow networks, fetch retry with exponential backoff, multi-stem streaming decode with lock-step seek and buffering recovery
- **Saved playlists & singer rotation (F1):** playlist CRUD (create, rename, delete), add/remove songs via library context menu, singer rotation with round-robin queue assignment, SQLite schema migrations (`008_playlists.sql`, `009_singer_rotation.sql`), full IPC command set, `en` + `zh-CN` i18n keys
- **Diagnostics:** About dialog with version + SHA, log rotation, redaction rules
- **Supply chain:** `SHA256SUMS` generated by CI for every release; `pnpm audit` green in CI; `cargo audit` last scan 2026-05-13 (0 vulns)
- **i18n:** `check-i18n.mjs` script validates `en` + `zh-CN` key coverage
- **DB schema doc:** `scripts/generate-db-schema.mjs` idempotent regenerator + `pnpm generate:db-schema`

### Fixed

- **Streaming playback:** contiguous cache reads over gaps, remote playback fallback and cache limit wiring, M4A probing, playback recovery after buffer underrun
- **H1 - Lyrics pipeline:** sync stall fix, plain-text layout, romanization language overrides, automated test coverage expansion
- **H2 - Remote libraries:** OAuth/WebDAV smoke tests, structured error handling per `phase-5-error-contract.md`, token redaction in logs, provider-specific error messages, missing-file handling after upload
- **H3 - Separation runtime:** ONNX provider selection stability, XNNPACK fallback, session lifecycle cleanup, limits documentation
- **H4 - AirPlay & presentation:** second-window fullscreen audience output contract alignment, gated test policy for CI
- **H5 - Packaging & supply chain:** WinGet/Flatpak manifest generators validated, release workflow permissions explicit
- **H8 - Model bootstrap recovery:** retry, clear cache, open folder paths
- **Playback UX:** Phase 6 playback-startup latency and beachball fixes, position clock accuracy (wall-time to render-frame), buffering state plumbing, empty path handling in Google Drive delete, scheduler recreation drain fix

### Changed

- **Architecture:** decomposed `AppState` into domain modules, extracted playback workflow with dependency injection, added `RemoteProvider` trait seam for cloud storage dispatch, replaced error string-matching with typed error enums, extracted `useEventSubscriptions` factory hook
- **Documentation ownership:** `F1-playlists-and-singer-rotation.md`, `queue-management.md`, and `releasing.md` updates
- **Forward-only migration policy** documented; F1 migration tests exist
- **Pre-release checklist** maintained in `releasing.md`
- **Code quality:** lefthook pre-commit hooks for Prettier + cargo fmt, 55 new tests for cache layer, lyrics parser, and frontend logic, singer rotation and queue filtering redesign

## 0.1.0 - 2026-03-16

- **i18n:** full internationalization with English and Simplified Chinese
- **Library operations:** batch separation, bulk delete, embedded lyrics extraction
- **CI/CD:** cross-platform pipeline (macOS, Windows, Linux), release automation (tag to GitHub Release with binaries)

### Fixed

- Eliminated audio crackling by using frame counter instead of wall clock
- Player bugs (seek, volume, pause, crackling) and UI layout overhaul

- Stabilized queue drag animations (migrated to dnd-kit)
