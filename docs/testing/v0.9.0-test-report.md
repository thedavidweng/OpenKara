## 3. 修复的问题

### ✅ Issue #1: 全局禁用浏览器右键菜单 — 已修复

**修复方式:** 在 `AppLayout.tsx` 根节点添加 `onContextMenu={(e) => e.preventDefault()}`，消除 WebView 默认菜单。

**相关代码:**

- `src/components/Layout/AppLayout.tsx:44` — 全局右键拦截

**验证:** `pnpm format` → `pnpm lint` → `pnpm build` → `pnpm test` 全部通过。

---

### ✅ Issue #2: 歌单无法添加歌曲 — 已修复

**修复方式:**

1. `playlist-store.ts` 新增 `playlistSongSets` 缓存和 `loadPlaylistSongSets` 方法，避免每次右键调用 N 次 `getPlaylistSongs`
2. `song-list-item-menu.ts` 扩展 `BuildSongListContextMenuItemsArgs` 参数，新增 `playlists`、`songPlaylistMembership`、`onAddToPlaylist`、`onRemoveFromPlaylist`、`onCreatePlaylistAndAdd`、`activePlaylistId`、`onRemoveFromActivePlaylist`
3. 在单选/多选菜单中均添加 "Add to Playlist…" 子菜单，带 checked/mixed indicator
4. 歌单详情视图中歌曲右键菜单新增 "Remove from Playlist" 选项
5. `SongListItem.tsx` 传入所有新参数，实现歌单归属查询和操作
6. 验收复核时补充：菜单操作使用当前右键目标集合，添加/移除后刷新 `playlistSongSets`，歌单详情视图监听归属缓存刷新

**相关代码:**

- `src/stores/playlist-store.ts` — `playlistSongSets` + `loadPlaylistSongSets`
- `src/components/Library/song-list-item-menu.ts` — "Add to Playlist…" 子菜单 + "Remove from Playlist"
- `src/components/Library/SongListItem.tsx:78-96` — 歌单归属查询逻辑
- `src/components/Library/SongList.tsx` — 歌单详情视图在归属缓存刷新后重新加载歌曲
- `src/locales/en.json:430` — `"newPlaylist": "[+] New Playlist…"`
- `src/locales/zh-CN.json:430` — `"newPlaylist": "[+] 新建播放列表…"`

**i18n 新增 key:**

- `playlist.addTo` ("Add to Playlist…")
- `playlist.newPlaylist` ("[+] New Playlist…")
- `playlist.removeFromPlaylist` ("Remove from Playlist")
- `playlist.addedToast`
- `playlist.createdAndAddedToast`
- `playlist.removedFromPlaylistToast`

**验证:** 所有本地测试通过。

### ✅ Issue #3: 歌手轮唱功能完全不可见 — 已修复

**修复方式:**

1. 新建 `src/stores/rotation-store.ts`，管理轮唱状态（active、singerNames、currentIndex、mode、queueSingers）
2. 新建 `src/components/Player/RotationControls.tsx`，提供 toggle + 歌手 tag 列表 + 添加歌手输入框
3. 修改 `QueuePanel.tsx`，在头部和列表之间插入 `RotationControls`；每个 `SortableQueueItem` 显示歌手名（active 时）
4. 修改 `SongListItem.tsx` 的 `playNext` / `addToQueue` 回调，当轮唱激活时自动分配下一位歌手
5. `AppLayout.tsx` 启动时调用 `loadRotation()` 从后端加载轮唱状态

**相关代码:**

- `src/stores/rotation-store.ts` — 轮唱状态管理
- `src/components/Player/RotationControls.tsx` — toggle + 歌手 tag UI
- `src/components/Player/QueuePanel.tsx` — RotationControls 集成 + 每行歌手字段
- `src/components/Library/SongListItem.tsx:427-440` — 入队时自动分配歌手
- `src/components/Layout/AppLayout.tsx:43-47` — 启动时加载轮唱状态

**验证:** 所有本地测试通过。
